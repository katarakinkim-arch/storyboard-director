# 技术连续性与输出契约

本文件是正式分镜必读的生产检查。创作方法可以变化，以下约束保持统一。

## 1. 台词校验

- 按原脚本逐行建立台词清单，角色名、OS、VO、传音、标点和顺序均保留。
- 每行独立台词只进入一个镜头；下一行必须新建镜头。
- 不把一行台词拆成多个镜头，也不把两行合并。
- 分行决定视觉切点，不自动增加语音停顿；同一句意群的声音可以跨切点自然连续。
- 用户明确指定某段一镜到底时，该段台词行改作镜内节拍，不再强制建立新编号。
- 镜头内可以发生焦点、构图或动作变化，但仍属于同一连续镜头。
- 无台词写 `台词：无`，不要混用“无”“（无）”“无。”等格式。

## 2. 语速与时间

正常语速基准：

> 5 秒约 18—19 个中文字。

估时先按字数得到基础值，再加入标点停顿、呼吸、动作和情绪留白：

- 激动、争吵、命令、抢答：可适当加快；
- 悲伤、迟疑、压抑、虚弱、哽咽：适当放慢；
- 重要判断和反转：允许留出短暂停顿，但不得滥用。

每章从 0 秒开始，总长不超过 30 秒。章节标题中的总时长必须等于最后一镜结束时间。

### 单镜时长的计算方式

单镜时长不是统一的1—3秒，而应覆盖：

> 识别主体所需时间 ＋ 动作／台词／信息变化所需时间 ＋ 结果停留与情绪落地时间

- **识别主体**：观众先知道在看谁、什么物件或哪个空间关系；
- **看懂变化**：动作完成、台词说清、线索出现或关系改变；
- **结果停留**：给观众确认结果、产生情绪或形成下一镜预期。

只有冲击插入镜头可以有意省略部分阶段。重要揭示若刚出现就切走，观众只能“看见”而不能“理解”。

### 诊断区间

以下只用于估时和发现异常，不是必须达到的配额：

| 镜头功能 | 常见可读时长 |
| --- | --- |
| 单一撞击、武器接触、极短插入 | 0.6—1.2秒 |
| 简单动作、明确反应、道具状态变化 | 1.2—2秒 |
| 普通动作或关系镜头 | 2—3秒 |
| 普通短台词 | 按字数计算，常见2—4秒 |
| 观察、犹豫、判断、关系转向 | 2.5—4秒 |
| 悬疑线索逐渐显现 | 2.5—5秒 |
| 情绪落地、重要选择 | 3—5秒 |
| 重要人物或未知对象首次完整揭示 | 3—6秒 |
| 强者高光、巨物尺度或庄重展示 | 4—7秒，必要时更长 |

动作强度、演员速度、焦距、运动距离和目标AI模型能力都会改变实际时长。不要为了符合区间拉长无信息镜头。

### 内容负荷检查

短镜头不应同时要求多个连续阶段。例如1.5秒内完成“胸口亮光—光扩散全身—双眼变化—海水变清—目标显现”通常不可读，也难以生成。

遇到以下情况时延长或简化：

- 使用“缓慢、逐渐、停顿后、环绕、从局部到全貌”等过程词；
- 一个动作必须先被观察、再被理解；
- 镜头内包含台词、走位、道具变化和运镜；
- 重要人物或巨物需要建立尺度；
- 爆点后需要让结果被看清。

### 节奏诊断

平均镜头时长（ASL）只用于发现节奏倾向，不作为目标。动作段可以短，悬疑、情感和奇观段通常需要更长观察时间。

若连续5镜以上都落在相近的1—1.5秒，且不是明确的蒙太奇、追逐或战斗快切，检查：

- 是否把同一动作拆得过碎；
- 是否用手、眼、绳索、环境等重复已有信息；
- 是否每个“缓慢推近”实际上都来不及完成；
- 是否缺少一个能让关键结果停留的长镜头。

用长短变化组织节奏，例如“短异常 → 稍长判断 → 完整决定 → 快动作 → 较长后果”，而不是整段保持机械等时切换。

## 3. 镜头编号与时间链

每个新镜头必须同时拥有：

- 新编号；
- 新起止时间；
- 画面；
- 运镜；
- 剪辑/动态效果；
- 台词。

检查：

- 镜头1起点是否为0；
- 后镜起点是否等于前镜终点；
- 是否存在时间重叠、空档、倒退或跳号；
- 章节是否超过30秒；
- 标称总时长和实际末尾是否一致。

## 4. 站位与轴线

多人关系、人物位移、动作、遮挡、群像和一镜到底场景先写轻量空间锚点：

- 关键人物的相对关系及必要的前／中／后景位置；
- 朝向、视线和行动路线；
- 门窗、家具、载具和关键道具位置；
- 主要人物连线形成的180°轴线；
- 摄影机统一所在轴线侧。

同场景后续镜头沿用该空间。若人物移动导致轴线变化，用跟拍、同框运动或中性正轴镜头让变化可见，不能无提示越轴。

单人静态、道具特写和纯环境镜头可以简化空间说明。后续镜头不重复初始坐标，只在位置、朝向、前后景、行动路线或控制权改变时更新。优先使用“谁靠近谁、谁挡住出口、谁从后景进入、人物向哪侧移动”等相对关系，不写无后续用途的精确画面坐标。

## 5. 动作接点

相邻镜头记录：

- 动作从哪个姿势开始；
- 手、脚、身体和视线向哪个方向运动；
- 道具在哪只手、哪个位置、什么状态；
- 上一镜动作完成到哪一步；
- 下一镜从哪个接点继续。

台词切镜不能使人物瞬间复位。动作结果必须在后续镜头持续存在。

对反复出现的身体细节、道具和环境母题，额外记录上次状态与本次状态。只有景别、角度或程度词变化，而位置、接触、受力、主动权和结果完全相同时，视为重复信息，不应单独占用镜头。

## 6. 景别、角度与运动

景别可使用特写、近景、侧面近景、中近景、中景、关系中景、过肩关系位、道具关系近景、前景遮挡中近景和必要的全景。

- 微距不作为默认景别，尤其不使用无叙事作用的人体局部微距；微小细节承担线索、材质、产品卖点、尺度变化或转场功能时可以使用，并须建立其空间关系；
- 少用无信息大全景；
- 同一场景避免叙事功能、表演状态和视觉关系完全重复，不机械轮换景别、主体、角度、遮挡和运动；
- 运动镜头比例不设固定值；
- 普通正反打和常规OTS合计最高约65%，只作机械化预警；
- 固定镜头能更准确表达时，不为“电影感”强行运镜；
- 对话人物之间避免无动机摇镜。

### 有动机的运动镜头触发机制

运动镜头不是固定镜头的装饰版本。只有当摄影机运动能让观众更清楚地读到位移、关系、信息、压力或结果时才使用；反过来，只要这些变化确实存在，也不能因追求安全而自动选择固定。

| 故事变化 | 优先评估的摄影机响应 | 必须明确的落点 |
| --- | --- | --- |
| 人物走近、追赶、撤退、绕行 | 跟拍、平行移、领先后退、短弧移 | 新距离、目的地、阻碍或动作结果 |
| 两人距离或权力关系变化 | 缓推、后拉、侧移重构双人关系 | 谁占据画面、谁被逼退、谁获得空间 |
| 阵营或多人关系重新组合 | 横移、升降、前景接力、稳定器调度 | 新站位和新的权力中心 |
| 信息从遮挡后或空间深处出现 | 侧移揭示、升降揭示、绕出遮挡、沿视线推进 | 被揭示对象与观察者的关系 |
| 动作具有连续路径 | 同方向跟随、贴地追随、随动作抬升或下降 | 接触、闪避、落地或后果 |
| 情绪逐渐逼近或认知收紧 | 极缓推或受控漂移 | 眼神、决定、沉默或不可逆判断 |
| 高潮结束、控制权确立 | 运动减速并稳定落幅 | 胜负、人物姿态、环境余震 |

同一镜头原则上只有一个主要运动逻辑。写清起幅、路径、速度变化与落幅，例如“从双人中景沿桌边缓慢侧移，绕出前景酒壶后落到被遮住的证物近景”，不能只写“电影感运镜”或“缓慢移动”。

### 稳定与固定的区别

- **固定**：摄影机位置与朝向不变，适合观察完整表演、制造无助、保持冷漠距离或让人物运动撞击稳定画框；
- **稳定运动**：摄影机沿清晰路径平顺移动，适合表现掌控、空间穿越、关系重构和渐进揭示；
- **不稳定运动**：手持、震动、急推、甩动只在突袭、失衡、主观恐慌或爆点需要时使用。

“强者越强，镜头越稳”优先理解为轨迹更稳、节奏更从容、落点更确定，而不是强者出现后摄影机必须静止。

### 连续固定镜头诊断

若连续三个镜头均写固定，逐镜检查：

1. 人物是否实际发生走近、后退、追赶或转移；
2. 关系是否从同盟变对峙、从可退变无路、从被动变主动；
3. 新信息是否从遮挡、门窗、后景或人物视线方向出现；
4. 是否存在可持续的动作路径或环境流向；
5. 固定是否确实承担观察、压迫、喜剧反差、强者控制或结果停留。

前四项任一成立且运动能提升可读性时，至少评估一个可执行运动方案。第五项成立时可以继续固定。此检查不形成运动镜头最低比例，也不要求机械地“每三镜动一镜”。

### 台词切镜中的运动连续性

一行台词对应一个镜头，不等于每句开始时人物和摄影机都复位。可以让同一视觉引擎跨镜延续：上一镜人物向前逼近，下一镜沿同方向后退保持距离；上一镜从门框后观察，下一镜侧移让关键人物进入画面；上一镜横移建立多人关系，下一镜运动减速落到作出决定的人。

对话人物之间仍不使用无动机来回摇镜。若只是从一个说话人摇向另一个说话人，且没有空间、权力或信息变化，应切换主体、利用过肩关系或保持同框，而不是用摇镜掩盖机械正反打。

## 7. 可执行描述

`画面`字段写镜头在其时长内能够看见的内容：主体、位置、动作、表情、环境结果。避免：

- “他像在看一件与自己无关的旧物”之类纯文学结论；
- 同一短镜头要求多个地点、复杂变形或无法连续完成的动作；
- 无依据的心理、世界观或特效补写；
- 只写“电影感、压迫感、高级感”而没有可见依据。

单镜允许一条连续的主要动作链。例如“起身—走近—封住出口”可以属于同一目标；“走近—复杂变形—多人反应—爆炸—环绕”则是多个争抢注意力的任务，应拆分或删减。

`运镜`字段说明固定或运动方式、角度、景别和必要速度。画面变化来自演员或环境时，不必强行移动摄影机。

`剪辑/动态效果`字段只写实际需要的速度变化、声音处理、遮挡衔接、匹配转场、焦点变化、色调转换、停帧、拖影、动态模糊或特效。场景转场须同时明确上一镜如何结束与下一镜从何种状态接出；打斗效果须保留清晰方向、接触点和唯一清晰落点；情感虚焦须写明焦点对象及转移时机。没有则写 `无`。

## 8. 输出前逐项核对

- 台词逐字、逐行、顺序一致；
- 每行台词对应唯一镜头；
- 时间链连续且每章≤30秒；
- 站位、轴线、动作、目光和道具连续；
- 每镜字段齐全；
- 镜头描述能在标注时长内完成；
- 无凭空新增剧情、设定或人物动作；
- 无连续机械单人脸覆盖；
- 重复视觉母题具有可见状态增量，不以同义小动作冒充推进；
- 结尾状态与下一章起点相接。
