# 对话场景的视觉叙事

本文件用于对话、对峙、暧昧、争执、审判和多人关系场景。目标不是减少台词，而是让台词发生在持续的行动和空间关系中。

## 1. 一行台词一个镜头，但动作不停

台词行决定切镜点，不决定每镜都重新站好说话。

一段持续动作可以跨越多行台词：

- 人物边下楼边被追问；
- 一方持续收拾、炼丹、包扎、开门或离开；
- 道具在不同人手中转移；
- 一方不断逼近，另一方不断寻找退路；
- 沉默第三人始终在场并改变对话含义。

每一行仍建立新镜头，但新镜头从上一镜动作接点继续。

## 2. 对话段落必须有视觉引擎

优先使用剧本已有的：

- **道具引擎**：丹药、婚书、武器、信物、门钥匙、酒杯；
- **距离引擎**：靠近、退开、并肩、隔开、堵住、擦肩；
- **任务引擎**：穿衣、疗伤、收拾、驾驶、寻找、递送；
- **空间引擎**：台阶上下、门内门外、桌子两侧、榻边和窗边；
- **观察者引擎**：第三人、动物、敌人、群众或镜中倒影；
- **秘密引擎**：不能被某人看见的东西或反应。

视觉引擎必须随台词推进发生变化，不能只是同一件道具反复做前景虚化。

## 3. 主体轮换必须携带信息

可以在说话人之外选择：

- 听者压住或泄露的反应；
- 两人同框的距离和高低；
- 第三人对关系的判断；
- 关键道具的状态变化；
- 被挡住或被让开的路线；
- 环境留下的结果；
- 人物拒绝看、只看手中物或越过对方看的动作。

不要为了“丰富”随机切手、眼、嘴、灯或空景。主体变化必须回答当前台词带来的新问题。

## 4. 多人场景保持关系几何

三人以上时，先定义：

- 谁与谁结盟；
- 谁被排除在外；
- 谁拥有行动路线；
- 谁位于前景、后景或两人之间；
- 谁能看见什么；
- 沉默者的存在如何改变说话者。

至少周期性回到关系镜头，让观众知道人物距离和权力是否变化。单人近景不能连续到让第三人从场景中消失。

## 5. 过肩与正反打的使用

OTS适合：

- 确认双方距离与对话方向；
- 让前景人物对后景形成压迫、保护或阻隔；
- 在同一轴线侧维持空间感；
- 让观众暂时依附某一方观察另一方。

不用OTS的情况：

- 重要动作发生在两人之间，需要完整同框；
- 第三人或道具比说话人的脸更重要；
- 角色拒绝建立直接关系；
- 连续OTS已经形成机械正反打。

普通正反打与常规OTS合计不超过单元约65%，这是上限而非目标。

## 6. 权力对话

权力不只靠仰拍。观察谁能：

- 决定是否停步；
- 控制距离；
- 让对方追赶、等待或退让；
- 占据出口、高位或行动路线；
- 无视对方的话继续完成自己的事；
- 决定何时结束场景。

强者掌控时优先保持构图和运动克制。只有爆点真正改变关系时才使用急推、甩镜或失稳；不要每句狠话都急推一次。

## 7. 情感与暧昧

情感场景使用：

- 犹豫后没有完成的动作；
- 触碰与收回；
- 呼吸、距离和视线变化；
- 同框中一人进入或退出另一人的空间；
- 物件、衣角、门、灯光等对关系的间接见证。

避免连续脸红、睫毛颤、喉结滚、泪水滑落。单个细节有效，重复就会成为模板。

用户人工设计的亲密动作只属于已确认段落。原剧本若写手腕，不得自行换成脚踝；原剧本若写手指，不得自行换成脚部动作。

## 8. 喜剧对话

喜剧通常依赖：

1. 铺垫一个正常预期；
2. 让动作或台词偏离预期；
3. 留出短暂停顿；
4. 用第三者、道具或后果回收。

吐槽角色不应只获得自己的正脸。可以让其处在窗棂、角落、高处或视线盲区，使其“看得见但别人看不见”的空间事实持续制造笑点。

## 9. 对话镜头自检

- 连续三镜是否都只是一张脸？
- 台词之外是否有一件事在持续发生？
- 沉默角色是否被遗忘？
- 关键道具是否仍影响视线和动作？
- 关系镜头是否足以让观众理解距离和站位？
- 每次近景是否真的揭示了新判断？
- 台词换镜是否意外重置了人物姿势或动作？

若答案暴露问题，先重建视觉引擎，不要只把固定近景换成缓推近景。
