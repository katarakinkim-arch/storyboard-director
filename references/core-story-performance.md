# 故事与表演决策内核

本文件是故事、人物、表演与逐镜选择的唯一规范来源。风格卡与案例只能提供候选方法。

## 场景故事骨架

先用一句话概括：谁为了什么，在什么阻力下采取行动，最后局面发生什么变化。若只能概括为“人物说了一段话”或“展示一个能力”，说明尚未找到故事引擎。

按需确定目标、阻力、代价、秘密、误判、选择、反转与后果，不要求每场都填满固定表格。每个章至少应具有清楚的起始状态和结束状态。

## 观众站位

确定观众此刻更贴近谁、比角色知道得多还是少、应该期待、怀疑、担忧、心疼或发笑。镜头信息量必须服务这一站位：悬疑可暂缓揭示，情感戏可保留沉默，喜剧必须保护铺垫与回收。

## 视觉引擎与状态阶梯

为一个场景或对话段选择一个可持续变化的视觉引擎，例如被争夺的道具、人物距离、退路、未完成动作、观察者视线、环境异常或权力控制。

同一母题再次出现时，至少改变位置、受力、接触、主动权、关系距离、道具状态、动作结果或观众认知中的一项。只把“蜷缩”换成“轻点”“颤抖更明显”，或只把近景改成中近景，不算新状态。

## 表演所有权

每句台词先判断观众最需要看什么：

- 说话人的表情或发声过程决定人物定级时，说话人拥有表演；
- 台词的力量体现在听者受创、动摇、误解或隐藏反应时，听者拥有结果；
- 台词伴随距离、阻挡、递交、夺取、触碰或退让时，关系动作拥有镜头；
- 道具或环境确实提供新证据、后果或隐喻时，才可成为主体。

关键宣言、威胁、决绝、谎言揭穿、情绪爆发和人物定级台词，不得仅为景别丰富切到无关局部。连续拍脸并非错误；若表演阶段真实变化，可以保护完整表演。

## 一行台词与视觉切点

用户已分行的台词默认代表视觉切点，用于避免一段长话停留在同一画面。新镜头必须产生故事相关的视觉增量，但不要求每次更换主体，也不自动制造语音停顿。相邻台词可在声音、呼吸、走位和动作上连续。

一镜到底是明确例外：台词行成为镜内节拍，摄影机通过调度、焦点、遮挡或距离变化完成视觉变化。

## 文学描述转为表演

把“害怕、后悔、强大、暧昧、愤怒”等抽象词转成可观察行为：呼吸改变、目光选择、话说到一半、握力变化、距离变化、动作中断、绕开某人、把物件放回或没有回头。

一个镜头以一条主要动作链为中心。允许同一因果链的连续动作，不同时堆入互不相关的走位、表演、变形、复杂运镜与多重特效。

## 关键节点择优

只为开场、首次揭示、关系逆转、核心爆点、重要出场、高潮和结尾钩子在内部生成 2—3 个方案。按故事清晰、人物准确、情绪效果、连续性和可执行性择优。普通过场不需要炫技。

主要高光遵循：铺垫或蓄力 → 事件落点 → 短暂停留 → 后果延续。每章优先只有一个主要高光，其余节点降低强度，形成层次。

## 摄影机与权力

摄影机稳定度表达人物控制力，但不是死规定。强者掌控局面时，稳定构图、平顺跟拍、可控弧移或缓推通常比无理由手持更准确；强者受袭、失控或主观崩塌时可以打破稳定。

稳定不等于固定。人物位移、距离变化、阵营重组或信息从遮挡后出现时，应主动评估跟拍、平行移、领先后退、升降、弧移和遮挡揭示。只有固定观察更能表现孤立、压迫、狼狈、控制或后果时才固定。

## 感知层变化

相邻镜头从主体、景别、摄影机高度、水平观察方位、前中后景、运动路径与叙事功能判断是否重复。“正面→微侧”“近景→中近景”“固定→无落点极缓推”若没有带来新空间、新表演阶段或新结果，仍属于同一视觉家族。

视觉丰富度是结果，不是目标。先让戏剧节拍改变观察需要，再改变镜头。

## 类型判断

- 悬疑：异常 → 证据 → 误判或威胁升级；
- 对话：目标与阻力持续存在，关系动作不断发展；
- 情感：克制行为、距离和选择比连续泪脸更有效；
- 喜剧：建立正常值 → 偏差升级 → 停顿 → 回收；
- 动作：攻击 → 应对 → 接触或落空 → 后果 → 新威胁；
- 奇观：参照物与环境后果先建立尺度，再完整揭示。

这些是诊断结构，不是必须逐项套用的模板。
