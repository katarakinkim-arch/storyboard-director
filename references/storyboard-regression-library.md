# 分镜失败回归库

本文件只用于维护、复盘和回归测试，不是创作案例库。普通生成不要通读或模仿其中内容。

## 回归001｜宫门旧人拦路：技术合格，故事站位错误

### 症状

- 台词、站位和字段基本正确，但主要依靠单人近景与常规正反打；
- 秦昭禾在后半场几乎从关系中消失；
- 宋芷云因泪水、特写和垮塌描写获得过多同情；
- 谢砚生的冷静被急推、震屏、停帧拍成失控怒吼；
- 台阶、薄霜、交握的手和离场路线没有形成贯穿母题；
- “像看旧物”“深不见底的凉”等文学结论不能直接表演；
- 结尾只完成“回家”，没有形成关系确认、余味或下一步推进。

### 根因

逐句配脸，没有先确定场景命题、观众情感站位、三人关系、权力变化和视觉引擎。

### 回归要求

- 先明确：宋想追回的究竟是人还是权势；谢要结束旧关系；秦是新关系成立的可见证据。
- 让“台阶高低／去路／交握的手”至少有一个贯穿并改变状态。
- 三人关系镜头不能让秦长期消失。
- 谢掌控局面时，摄影机总体克制；爆点来自内容和结束权，不靠每句急推。
- 抽象心理转成停步、追赶、拒绝回看、让路、握手力度等动作。

## 回归002｜洞府后半段：强开场之后创意塌缩

### 症状

- 开头有明确身体动作、空间张力和关系反转；
- 进入渡鸦与丹药段落后，迅速退化为“角色正脸固定镜头”轮流说话；
- 渡鸦被拍成孤立鸟脸，未成为空间观察者与喜剧节奏来源；
- 丹药虽是冲突核心，却没有持续控制人物视线、走位和权力；
- 每个新单元像重新开场，上一段形成的距离、姿势和暧昧后果消失；
- 静态无台词动作与静态台词脸分离，台词没有骑在持续行动上。

### 归属说明

“脚从大腿滑到胸口”和“扣住脚踝”是用户人工添加，不是 AI 自动生成。不得把它们当作模型成功案例，也不得由此获得把原剧本“手指擦过心口／扣住手腕”改成脚部动作的权限。

### 回归要求

- 每个对话单元确定一个持续视觉引擎；丹药、未完成动作、人物距离和渡鸦视线都可承担。
- 一行台词一个镜头时，动作和空间仍跨镜继续，不能复位。
- 定期使用双人或三方关系位，让沉默角色和观察者保持在戏中。
- 新单元继承上一单元的动作结果和创意语言，不自动回到正反打。
- 手腕、脚踝、手指等原动作严格按脚本；人工改动只保留在用户确认的版本内。

## 回归003｜案例误学：把“不错”当成“最高标准”

### 症状

- 用户只认可部分镜头设计，却被记录为全盘优秀；
- 连案例的字段、单元长度、台词拆分和特效习惯一并复制；
- 海上悬疑的黑雾、暗红光等美术元素扩散到无关场景。

### 回归要求

- 案例必须记录评价等级、学习边界和内容来源。
- “不错／选择性参考”只提取明确优点，不当模板。
- “仅学习分镜”不得继承格式。
- 风格元素只有在当前剧本和世界观支持时使用。

## 回归004｜等时碎切与渲染通胀

### 症状

- 大量镜头都在1—1.5秒，观察、判断、悬疑和巨物揭示没有识别与停留时间；
- 镜头写着“缓慢推近、逐渐显现、完整环绕”，实际时长不足以完成；
- 同一关键节点叠加急推、慢动作、仰拍、环绕、震屏、粒子、强光和多人反应；
- 每个角色出场都使用脚步、衣角、背影、正脸的同一仪式；
- 高光只在当镜有效，下一镜人物关系、伤势、道具和空间立即复位。

### 回归要求

- 单镜时长覆盖识别主体、看懂变化和结果停留；平均镜头时长只作诊断。
- 关键时刻先分主要、次要与普通层级，主要时刻才使用完整的铺垫—落点—停留—后果。
- 同一高光选择一种主强化和最多一种辅助，不堆满所有效果。
- 重要人物通过到场影响、定义性行动和关系确认进入故事，不统一套出场模板。
- 高光结果必须延续到后续镜头，摄影机渲染不能替代故事变化。

## 回归005｜视觉母题原地踏步：脚部小动作同义重复

### 用户评价范围

用户明确认为第一组脚部设计不好，因为镜头1、3、4虽分别写“蜷缩又松开、重心前倾、脚趾点地”，实质上都在表达同一种示弱与不安，看不出新的状态变化。

用户认为第二组“关于脚的变化还不错”，只认可其脚部母题具有较明显的阶段推进；这不代表第二组整体分镜均为优秀。第二组单元末尾达到32.5秒，仍违反当前每单元不超过30秒的规则，该时长和整体格式不得学习。

### 反例症状

- 同一身体部位连续承担多个镜头，但每次都只表达“紧张、委屈、撒娇”；
- 用“微微、轻轻、一下又一下、更加、持续”等程度和频率词制造表面差异；
- 从脚部特写换到近景或低机位，却没有改变人物位置、受力和关系；
- 母题成为装饰，台词与空间关系仍停在原地。

反例中的脚部状态可归并为一个阶段：赤脚内扣、蜷缩／点地／轻颤，均服务于示弱。除非中间发生新的动作或权力变化，不需要分别建立多个脚部镜头。

### 正向对照中可学习的状态链

1. **后退半步**：人物主动退让，冲突开始进入空间行动；
2. **不断后退至背靠石台**：退路从存在变成消失；
3. **靴尖贴住赤脚**：对手越过身体边界，压迫从语言落到接触；
4. **脚趾蜷缩到极限**：关键台词落下时，身体反应跨过新的压力阈值；
5. **双脚钉在原地**：不是再次紧张，而是行动能力被压住的结果；
6. **对方离开后脚趾才微动**：压力解除后的余震，表现想回应却仍未行动。

该链条可学习的是“位置—阻断—接触—阈值—僵住—余震”的可见推进，不得复制赤脚、靴尖、暧昧接触或具体人物关系到无关剧本。

### 回归要求

- 视觉母题再次出现前，记录上次状态和本次状态；至少改变位置、接触／受力、主动权、关系距离、道具状态或动作结果中的一项。
- 景别、角度、运镜和程度副词变化不能替代故事状态变化。
- 若连续两次母题只表达同一种情绪，合并、删除，或改拍对手行动、关系位、空间后果和第三者反应。
- 程度升级必须越过明确阈值并改变观众理解，否则“微颤→更颤→持续颤抖”仍是重复。
- 用户对第二组的认可仅限脚部变化，不扩展为对其时长、格式、台词处理和全部镜头的认可。

## 回归006｜洞府暗算：毒火效果升级替代行动意义

### 用户评价范围

用户明确要求把这组八镜头分镜作为“不好的案例”存储。案例内容为：江凡在洞府内打坐，姬野从窗外窥视；姬野先凝出深紫毒火，观察后说“太便宜他了”，再把毒火变成更亮、更冷的幽蓝细线，穿过窗缝打入江凡下腹，导致其灵气中断。

本条只用于识别暗算场景中“效果很丰富，但行动选择和故事后果没有被讲清”的失败模式。不得把江凡、姬野、毒火、丹田、窗缝、霜花或具体台词复制到其他剧本。

### 反例症状

- “太便宜他了”暗示人物放弃直接杀死、改用更残酷的办法，但后续只表现火焰更亮、更冷、颜色改变，观众无法理解手段的功能发生了什么变化；
- 镜头3与镜头6都以指尖毒火特写、凝聚和霜花为主体，区别主要依靠颜色、亮度和“更多／更低”等程度升级，没有形成新的行动状态；
- 镜头4与镜头5连续使用姬野近景表达评估、嫌弃与不甘，台词再次解释上一镜已经表现的情绪；
- 镜头2至镜头8高度集中于固定近景和特写，缺少窗外窥视者、窗缝、室内目标及攻击路线的关系构图，画面成为断开的局部插图；
- 八镜头几乎全部为2—2.5秒，观察、决定、出手和命中被拍成等重节拍，没有“观察蓄力—决定停顿—突然出手—结果落地”的速度差；
- 深紫／幽蓝强光、霜花扩散、明显拖尾、灵气四散、灯火剧烈摇曳和影子扭曲同时出现，与“悄无声息穿过窗缝”的隐蔽暗算互相冲突；
- “几乎没有温度”“温度更低”“像是在评估”“觉得直接杀了太便宜”等解释性文字不能直接表演或由画面验证；
- 摄影机先写在窗外，随后姬野的眼睛又占据窗缝，却没有先建立两人的具体位置、视线方向、窗缝高度与毒火命中下腹的射线；
- 结尾只确认“毒火命中、灵气中断”，没有让观众理解江凡是否察觉、毒火将造成什么已由原剧本支持的后果，以及这为何比直接杀死更符合姬野的选择。

### 根因

把“特效状态”误当成“故事状态”。设计先考虑毒火颜色、霜花、拖尾和灵气波动，没有先回答：姬野原本准备做什么、哪一刻改变主意、改变后的手段与目标有何不同、江凡因此进入什么新处境。

同时没有明确观众站位与主高光。观众既没有稳定贴近窗外猎人，也没有充分停留在室内不知情者；毒火生成、台词决定、形态变化、飞行和命中又被平均渲染，导致没有一个真正主要的转折。

### 回归要求

- 暗算场景先确定行动选择链：观察目标 → 原计划或初始冲动 → 新证据／判断 → 手段改变 → 执行 → 可见后果。若原剧本没有“改变手段”，不得为了制造狠感擅自增加。
- “太便宜他了”一类决定性台词之后，下一步必须让观众看见策略、目标、功能或代价发生变化；不能只把同一法术换颜色、加亮度和增加粒子。
- 原剧本没有说明毒火会废修为、长期潜伏、折磨或致死时，不得自行选择其中一种后果。只表现剧本支持的现象；缺失信息会改变剧情时再向用户确认。
- 同一特效母题再次出现，至少改变形态功能、攻击目标、隐蔽程度、控制权或结果中的一项。“紫色→蓝色”“微光→更亮”“少量霜花→更多霜花”本身不构成有效推进。
- 先用一枚关系镜头建立窗外藏身位置、窗缝、室内江凡、视线方向和攻击路径；随后特写才能被观众放回正确空间。窗缝高度与命中部位不在合理直线上时，需要法术转向依据或调整站位。
- 固定镜头可以服务姬野的冷静掌控，不要求为了比例增加运镜；但连续近景必须更换有效主体或景深关系，如目标、视线、窗缝、手段变化和结果，不能只换一张表情脸。
- 隐蔽攻击的声光强度必须与“是否会被发现”一致。除非剧情明确让江凡察觉，否则强光、长拖尾、大范围结霜和剧烈灵气爆发应克制或提供不被察觉的设定依据。
- 单镜时长按任务分配：观察与判断允许停留，决定形成明确停顿，出手可以突然加速，命中后给后果确认；不要把不同信息量的镜头统一写成2—2.5秒。
- 把解释性心理转成可见选择，例如指向致命部位后停住、视线移向另一目标、火焰由外放转为收束、手势或攻击路径改变。具体动作必须来自当前剧本设定，不能把示例动作当默认答案。
- 单元结尾至少留下一个由原剧本支持的问题或后果：受害者是否察觉、异常是否潜伏、攻击者是否撤离、修炼状态是否改变。若这只是更长场景的一部分，则下一镜必须继承命中结果，不能复位。

### 不应误伤的做法

- “室内安静修炼／窗外猎人窥视”的内外反差可以保留；问题在于空间关系未被充分建立，不在于这个开场思路本身。
- “凝聚—出手—命中—反应”的动作因果可以保留；问题在于决定性台词没有真正改变这条动作链。
- 固定摄影机、近景和特写不是天然错误。人物高度掌控且场景追求静默时可以大量使用，但主体、信息和前后景状态仍要推进。
- 如果世界观明确规定毒火颜色变化代表不同功能，并且观众此前已经理解该规则，颜色变化可以承担信息；否则必须用动作、目标或结果帮助观众读懂。
