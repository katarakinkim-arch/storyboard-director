# Privacy Policy

Effective date: 2026-08-18

Storyboard Director is a skills-only plugin. The plugin contains instructions and reference material for turning user-provided scripts into storyboard plans. It does not operate an external server, create user accounts, use advertising trackers, or independently collect, store, sell, or share personal information.

Content supplied while using the plugin is processed by the product in which the plugin is running. That product's privacy terms and data controls apply. Users should avoid including confidential, personal, or rights-restricted material unless they are authorized to process it in that product.

The plugin may be updated over time. If a future version adds an external service or new data handling, this policy will be updated before that capability is released.

Questions or privacy requests can be submitted through the repository's public support page:

https://github.com/katarakinkim-arch/storyboard-director/issues
