# 成品分镜质量闸门

初稿不是交付稿。正式输出前必须在内部完成以下六轮审片，并直接修订失败镜头；不得只确认规则文字存在。最多进行两轮集中修订，仍有会改写剧情的歧义时才向用户说明。

## 第一轮｜剧本与世界观

- 台词、OS、VO逐字逐行、顺序和归属一致；
- 不新增剧情结果、人物能力、世界规则或关系事实；
- 内在状态只能使用剧本或既有设定已经建立的视觉表现。未经建立的经脉显影、空间壁障、眼睛发光、颜色等级、精神世界和环境异变不得直接写成事实；只能删除、采用中性身体反应，或标注为待用户确认的备选方案；
- 风格库、导演卡和案例只能改变表达方法，不能补写设定。

## 第二轮｜时间与单镜负荷

- 时间连续、每章从0开始且不超过30秒；
- 台词时长符合语速，动作具有起点、过程和可读结果；
- 一镜只保留一个主要阅读点和一条主要动作链；
- 运镜、表演、走位、特效和环境变化不能在短时长内同时争抢；
- “缓慢、逐渐、完整环绕、停顿后”等过程词必须有足够时间。

## 第三轮｜状态与跨章交接

对人物、动物、载具、伤势、服装、关键道具、能力效果和环境状态建立章末—章首交接表：

| 项目 | 上一章末状态 | 下一章首镜继承方式 |
| --- | --- | --- |
| 位置／支撑面 | 在哪里、靠着或站在什么上 | 保持原位或拍出移动 |
| 朝向／视线 | 面向谁、看向哪里 | 保持或给出转向动作 |
| 接触／持有 | 谁抓着谁、哪只手持何物 | 继续保持或拍出交接 |
| 伤势／服装 | 伤口、血迹、破损、湿润 | 后续可见状态一致 |
| 能力／环境 | 光、烟、火、水、天气、破坏 | 延续、衰减或结束有依据 |

章节计时归零不代表故事状态归零。遮挡只能隐藏一段已经合理发生的移动，不能自动授权换位；同时检查移动动机、可用时间、可行路径、速度和落点。

## 第四轮｜摄影机几何、轴线与前景

- 摄影机位置、镜头方向、人物左右关系和移动方向能够画成一致的空间图；
- 前景对象确实位于摄影机与主体之间，尺寸符合距离和镜头透视；
- 摄影机不穿过人物、墙体、家具或载具；
- 单人且尚未建立关系轴时，可以使用较大角度环绕；
- 双人对话、追逐、攻防或屏幕方向已建立后，默认只在轴线同侧弧移；完整360°不得覆盖该规则；
- 确需过轴时，必须在一个可见连续运动、中性正轴镜头或共同移动中完成，并在落幅重新建立人物左右关系。

## 第五轮｜感知层视觉重复

比较相邻镜头的主体、景别、摄影机高度、水平观察方位、前中后景、运动路径与叙事功能。以下通常仍属于同一视觉家族：

- 平视改成微俯或微仰，但观众几乎感受不到高度改变；
- 正面改成正面微侧，水平变化约15°以内且没有新的遮挡或关系；
- 近景改成中近景，但主体占比和背景信息没有明显改变；
- 固定改成没有明确起幅、路径与落幅的极缓推；
- 只改变表情程度、光效亮度、粒子密度或形容词。

15°只作感知诊断，不作为机械测量标准。若普通观众第一眼仍会认为“还是同一个画面”，就按重复处理。修复顺序为：合并同一阶段 → 重建戏剧节拍 → 改变观察任务 → 最后才改变角度或运动。不能随机切脚、手、空景和无关道具。

## 第六轮｜表演所有权与配角克制

- 威胁、宣言、谎言、决绝、认知转折和人物定级，优先保护承担表演的人；
- 动物、沉默配角和背景人物只有在获得新信息、承受环境影响、改变行动、形成空间参照或完成喜剧回收时才被强调；
- “它仍在场”只需要位置连续，不要求每镜给反应；
- 同一配角连续反应若没有新功能，应保留在同框中而不接管焦点；
- 视觉多样性不能覆盖剧情、连续性、可执行性和关键表演。

## 交付条件

只有六轮全部通过，才能输出正式分镜。修订后重新检查被修改镜头的前后两镜与章间交接，防止修复重复时制造瞬移，或修复连续性时错过关键表演。
