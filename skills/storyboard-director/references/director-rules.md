# 商业AI短剧 / AI漫剧导演规则库

# 1. 开场爆款点

每一集开场必须设计观众继续观看的理由。

不要把剧本第一句机械地当成第一镜。

首先判断：

本集最值得观众在开场看到的东西是什么？

可以来自：

- 上集悬念承接
- 危险
- 反常画面
- 强动作
- 人物异常行为
- 未知信息
- 秘密
- 人物关系冲突
- 身份反差
- 喜剧反差
- 特殊道具
- 系统异常
- 强者
- 危机
- 明确的问题
- 结果先行
- 强视觉奇观

原则上：

开场前3—8秒内至少建立一个观看问题。

例如：

怎么回事？

她为什么这样？

这是谁？

那是什么？

他想干什么？

接下来会怎么样？

吸引力不等于快切。

允许：

快速猛烈。

也允许：

极度安静、
异常、
压迫、
悬疑。

真正判断标准：

【观众是否想看下一秒？】

禁止为了爆款开场：

新增重大剧情；

制造与后文无关的假悬念；

提前泄露核心谜底；

强行加入爆炸或战斗；

加入与剧情无关的炫技镜头。

---

# 2. 台词保护

原剧本：

角色台词、
OS、
VO

不得：

删除、
改写、
调换顺序、
擅自新增。

一行独立台词一个镜头。

一行台词结束后切镜。

不得将两行独立台词合入同一个镜头。

但：

一行台词一个镜头

不等于：

一个台词一个正脸。

台词期间允许拍：

- 听者
- 说话人背影
- 手部
- 道具
- 空间
- 环境
- 视线对象
- 台词涉及对象
- 事件结果
- 回忆
- 想象
- 人物行动

OS、VO：

默认人物不开口。

---

# 3. 单镜头承载能力

镜头描述不得超过：

当前时长 + 当前运镜

能够实际承载的内容。

例如：

2秒镜头禁止同时安排：

跑步
+
转身
+
拔剑
+
挥剑
+
爆炸
+
镜头环绕
+
建筑倒塌。

如果时间内无法自然完成：

必须拆镜。

一个镜头优先只有：

一个主要视觉主体；

一个主要动作；

一个核心信息；

一种主要运镜。

---

# 4. 分镜单元

整集根据戏剧阶段拆分分镜单元。

例如：

- 入场
- 信息建立
- 观察
- 试探
- 对峙
- 喜剧
- 冲突升级
- 信息反转
- 情绪变化
- 机制触发
- 高潮
- 钩子

原则上：

单元不超过30秒。

不要机械每30秒强切。

---

# 5. 站位与180°轴线

正式拆镜前：

必须先确定人物和空间。

明确：

谁在画面左侧；

谁在中央；

谁在右侧；

谁在前景；

谁在后景；

人物面对方向；

重要道具；

门；

窗；

家具；

人物行动路线；

主要对话轴。

建立轴线后：

保持同一180°区域。

禁止无理由越轴。

如果人物移动导致轴线改变：

通过人物运动、
中性镜头、
正轴镜头、
重新建立空间

完成新轴线建立。

---

# 6. 构图与景别

主动变化：

景别；

主体；

角度；

焦点；

前景；

构图；

运动方向。

可以使用：

特写

近景

侧面近景

低机位近景

中近景

中景

人物关系位

OTS

道具近景

前景遮挡

微俯

低机位仰拍

门框构图

窗框构图

桌面遮挡

床幔遮挡

人物背影

长焦压缩

局部环境

少量全景 / 大全景

禁止大量连续：

平视人物正脸；

A正脸 → B正脸 → A正脸；

完全相同OTS；

完全相同景别；

完全相同推镜。

但：

不得为了“镜头变化”随机改变合理机位。

剧情表达 > 镜头花样。

---

# 7. 运镜规则

## 情绪平静

固定

稳定构图

缓推

缓移

## 人物观察

轻推

焦点转换

侧移

## 暧昧

缓推

前景遮挡

柔和横移

## 试探

稳定OTS

慢推

## 压迫

低机位

长焦

缓慢逼近

## 人物高光

仰拍

稳定长镜

克制慢环绕

前景揭示

## 人物进入

低机位跟拍

前景揭示

## 冲突

短促推进

快切

横移

## 爆点

允许：

急推

甩镜

骤停

速度变化

## 追逐

跟拍

低机位

侧向移动

## 大型异象

首先快速建立异常。

随后：

降低运动速度。

当奇观完整出现时：

优先稳定、
缓慢、
克制。

越大的东西：

最终揭示镜头越稳定。

禁止：

无意义旋转；

无意义环绕；

无意义穿越；

持续高速移动；

所有镜头都推镜。

---

# 8. 节奏

禁止整集维持同一种速度。

主动建立：

快 → 慢

慢 → 快

紧 → 松

松 → 爆

爆 → 停

重要信息揭露前：

允许停顿0.5—1秒。

喜剧包袱落下后：

允许多停0.3—0.8秒。

强者正式出场：

降低切镜频率。

大场面最终展示：

降低切镜频率。

普通信息：

快速清楚完成。

---

# 9. 视觉叙事

不要所有信息都依赖人物正脸。

主动寻找：

【可以拍的东西】

例如：

台词说六个人被淘汰：

拍六个名字被划掉。

台词说有人受伤：

拍伤势。

台词说没人敢进去：

拍所有人停在门外。

台词说众人盯着孩子：

进入孩子视角。

台词提到危险：

让危险道具进入前景。

原则：

能通过画面表达的内容：

不要全部让演员说。

---

# 10. 反应镜头

反应镜头必须具有剧情价值。

不要角色每说一句话就切一次反应。

真正值得反应镜头的情况：

信息首次揭露；

关系变化；

认知反转；

恐惧；

杀意；

权力变化；

喜剧落点；

误解；

重大决定。

普通听话：

可以通过关系镜头解决。

---

# 11. 喜剧

喜剧不是只有台词。

使用：

台词
+
动作
+
节奏
+
构图
+
反差

例如：

角色刚躲过一个茶杯。

不要马上恢复正常。

可以：

保持后仰
→
停一拍
→
慢慢站回来
→
看碎瓷
→
看对方
→
再说话。

视觉动作应跟随台词升级。

例如：

“护额？”

认真比额头。

“头盔？”

动作扩大至整个头。

“锅盖？”

目光直接落到旁边锅盖。

---

# 12. 重要人物出场

重要人物首次出现、
重新出现、
身份改变、
黑化、
蜕变、
暴露实力时：

都必须单独设计。

首先判断：

【此刻观众应该怎样感受这个人物？】

---

## 强者 / 权力人物

目标：

控制感。

推荐：

环境变化
→
别人停下
→
空间让开
→
人物进入
→
完整人物
→
动作 / 眼神
→
台词。

适合：

低机位

长焦压迫

稳定构图

慢推

克制环绕

大面积人物占屏

正式建立气场后：

降低切镜频率。

---

## 反派 / 危险人物

目标：

先感到危险，
再真正看清是谁。

可以首先表现：

行动结果；

危险道具；

手；

脚步；

影子；

背影；

环境异常；

其他人的行为改变。

真正危险的反派：

不一定需要高速镜头。

有时：

越稳定，
越正常，
越危险。

---

## 神秘人物

核心：

控制信息。

可以：

局部
→
轮廓
→
行为
→
声音
→
部分身份
→
完整人物。

不要一次全部揭示。

---

## 救场人物

先表现：

局势发生变化。

例如：

攻击突然停止；

武器被挡；

众人改变视线；

风向改变；

危险物碎裂；

一个声音出现。

之后：

再揭示是谁来了。

---

## 喜剧人物

不要使用强者式登场。

可以：

异常构图
→
奇怪动作
→
其他人正常反应
→
本人一本正经出现。

---

## 美型 / 魅力人物

不要只拍脸。

可以：

姿态
→
服装
→
动作
→
空间关系
→
完整人物
→
面部。

魅力来自整体存在感。

---

## 隐藏实力人物

人物表面普通时：

镜头同样可以保持普通。

不要使用明显高手镜头提前泄密。

真正暴露实力时：

突然改变：

景别；

机位；

人物占屏；

运动速度；

镜头稳定程度；

环境反应。

制造视觉反差。

---

## 黑化 / 蜕变 / 身份变化

镜头语言必须让观众意识到：

【这个人已经和以前不同。】

可以改变：

进入方式；

角度；

占屏比例；

光线；

动作速度；

空间距离；

节奏；

镜头稳定程度。

---

## 禁止套路化

禁止所有人物都：

脚步
→
衣角
→
背影
→
脸。

禁止：

每个强者都环绕；

每个反派都黑影；

每个美女都从脚拍到头。

人物出场设计必须来源于：

【人物此刻的剧情意义】

---

# 13. 强者高光

强者气场真正建立后：

尽量不要不断切其他人物震惊脸。

优先让环境表现压迫：

风停；

雾散；

火焰偏移；

瓦片震动；

人群退后；

空间突然安静。

让世界响应人物。

---

# 14. 大场面 / 异象

奇观不要第一次出现就交代全部答案。

使用：

异常
→
局部
→
更多局部
→
观众猜测
→
建立尺度
→
完整全貌。

例如巨大莲花：

云层异常；

巨大晶体弧面；

第二片；

第三片；

观众发现所谓晶体山壁是花瓣；

最终显露完整巨莲。

尺度通过：

人物；

城市；

建筑；

宫殿；

山峰；

云海；

河流

建立。

禁止单纯写：

巨大。

震撼。

宏伟。

必须让视觉真正证明尺度。

---

# 15. 空间与转场

不同场景不应全部硬切。

适合时寻找：

前景遮挡；

颜色匹配；

物体匹配；

动作匹配；

光冲镜；

镜面；

门框；

倒影；

液体；

形状匹配；

卡牌。

例如：

宫灯 → 下一场暖色灯光

卡牌下坠 → 倒影 → 新场景

杯口 → 圆形物体

人物经过柱子 → 遮挡 → 新场景

强光 → 新空间

但：

不要每个场景都强行做高级转场。

---

# 16. 系统 / 卡牌 / 特殊机制

存在：

系统；

卡牌；

技能；

一次性物品；

BUFF；

诅咒；

奖励

时：

必须表现完整生命周期。

观众必须知道：

何时获得；

何时储存；

何时感应；

何时触发；

何时消耗；

何时消失。

例如一次性卡牌：

① 获得

② 储存

③ 感应

④ 正式触发

⑤ 消耗

⑥ 消失

感应阶段：

不得提前让卡牌碎裂或消失。

正式消耗：

必须出现明确结果。

例如：

裂纹；

光化；

燃烧；

粒子化；

消散。

必要时可以短暂出现：

【已触发】

【已使用】

UI必须：

短、
轻、
自然。

不要破坏影片世界观。

---

# 17. 参考图连续性

场景参考图必须尽量保持：

房间结构；

门窗；

床；

柱子；

桌椅；

颜色；

光线方向；

空间纵深。

不能每切一个镜头：

房间就像变了一个地方。

角色必须保持：

脸；

年龄；

发型；

服装；

体型；

身份气质。

道具必须保持：

造型；

尺寸；

材质；

颜色；

当前状态。

---

# 18. AI视频生成友好

每个镜头重点突出：

1个主体；

1个主要动作；

1个核心情绪 / 信息；

1种主要镜头运动。

文字必须：

具体；

可视化；

空间明确；

方向明确；

动作明确。

避免：

纯文学描写；

角色瞬移；

动作过多；

空间模糊；

极复杂长镜；

一个镜头完成多个剧情阶段。

复杂动作：

拆镜。

---

# 19. 集尾钩子

最后一个分镜单元必须产生：

【继续观看下一集的动力】

可以来自：

新人物；

门打开；

一个眼神；

隐藏信息；

道具启动；

卡牌触发；

敌人到来；

重大异象；

没有回答的问题；

意外决定。

最后1—3镜：

降低“事情已经结束”的感觉。

禁止仅仅：

人物离开；

大家散去；

场景结束。

---

# 20. 最终自检

正式输出前检查：

原台词是否100%保留？

是否漏台词？

是否修改台词？

是否改变台词顺序？

是否一行台词一个镜头？

OS / VO是否正确？

无台词是否写“台词：无”？

开场前3—8秒是否有吸引点？

第一镜是否值得成为第一镜？

是否制造假悬念？

是否擅自增加剧情？

重要人物出场是否经过设计？

人物出场方式是否符合当前剧情功能？

是否所有重要人物都用了相同出场套路？

隐藏强者是否提前被镜头剧透？

单镜头内容是否超过时长承载能力？

镜头时间是否连续？

分镜单元是否自然？

是否为了10镜头机械凑镜？

是否越轴？

人物位置是否连续？

人物视线是否连续？

动作是否连续？

道具是否连续？

场景是否符合参考图？

人物是否符合参考图？

OTS是否机械重复？

普通正反打是否过多？

是否大量连续平视正脸？

景别是否具有变化？

运镜是否具有剧情原因？

是否存在无意义环绕？

是否存在无意义推镜？

关键动作是否拍清楚？

喜剧是否具有动作、停顿和构图？

反应镜头是否过多？

强者气场是否被大量反应镜头打断？

大场面是否存在尺度参照？

大场面最终展示是否足够稳定？

系统、技能、卡牌生命周期是否清楚？

一次性能力是否明确消耗？

转场是否自然？

集尾是否产生下一集观看动力？

如果任意关键检查不合格：

先修正。

修正完成后：

再输出。
