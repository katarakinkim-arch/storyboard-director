# 特殊场景导演工具箱

本文件不是全场通用配方，只在 `SKILL.md` 指定的特殊段落按需读取。先执行故事优先分析和技术连续性，再选择少量真正有用的方法。

## 1. 开场

开场目标是在前3—8秒建立一个值得继续看的问题。优先从原剧本已有内容中寻找：

- 正在发生的异常或危险；
- 人物强烈欲望与即时阻力；
- 身份、关系或行为反差；
- 一个即将完成却被打断的动作；
- 有代价的信息或选择；
- 视觉奇观的一部分，而非无来由全貌。

可用方法：从结果反推原因、局部先于全貌、声音先于主体、以动作进入、把关键物件放在人物关系中。

不得新增原剧本不存在的绑架、袭击、亲密动作、死亡、能力或反转。强开场建立的视觉引擎应影响后续章节，不能只做一次性噱头。

## 2. 人物出场

重要出场不是展示人物外形，而是让人物进入故事并改变场内秩序。先确定：

- 他为什么在此刻出现？
- 他出现后谁的目标、判断或行动被改变？
- 观众此刻应该感到威胁、希望、诱惑、好奇、权威还是反差？
- 观众需要立即知道多少，应该暂时保留什么？

### 出场的四个功能阶段

不要求四阶段各自成为独立镜头，但完整出场通常需要覆盖：

1. **原有秩序**：人物出现前，场内正在发生什么，谁暂时掌控局面；
2. **到场影响**：声音、视线、让路、环境变化或行动结果先证明“有人来了”；
3. **定义性行动**：角色用一个符合人设、且改变现场的行为完成出场，而不是只摆姿势；
4. **关系确认**：用关系位、视线或后果确认他与主角、对手和空间的关系。

根据剧情功能选择差异化方式：

- **权力人物**：别人先让路、停声或改变行为；人物进入后构图趋稳。
- **危险人物**：先出现其造成的后果、视线或空间反应，再决定是否露脸。
- **神秘人物**：控制信息而非一味遮脸；保留一个具体可追问的问题。
- **救场人物**：先让危机逼近，再以改变结果的行动证明到场。
- **喜剧人物**：从错误时机、空间位置或他人预期落差进入。
- **魅力人物**：用行为、节奏、他人目光和环境互动建立，不套用脚步—衣角—背影—脸。
- **隐藏实力人物**：日常状态与一个不经意的准确动作形成反差。

### 出场时长与镜头完整性

- 首次完整揭示通常需要比普通反应镜头更长的识别和停留时间；参考3—6秒，根据动作和信息量调整。
- 定义性行动尽量完整，不在动作尚未建立人物气质时切给无关反应。
- 反应镜头放在行动落点之后；如果出场的核心就是“别人如何被他影响”，可以让关系反应成为主体。
- 出场后的1—2个镜头内，应让人物参与当前目标或冲突，避免成为与剧情脱节的MV式展示。
- AI执行复杂时，优先保留“到场影响—定义性行动—关系确认”，减少同时发生的群众反应、复杂环绕与多重特效。

### 出场视觉签名

可为重要人物选择一个与人设和剧情相关的视觉签名，例如稳定度、运动方向、空间高度、前景关系、声音留白或环境反应。后续高光可以轻度回收，但不能让签名替代人物行动。

重要人物出场不等于必须仰拍、环绕或慢动作。禁止统一套用“脚步—衣角—背影—脸”，也禁止同时叠加慢动作、低角度、360°环绕、强光、全员反应和专属音效。

### 势力群像与领袖压轴

多人共同出场时，先判断剧情要展示的是平等伙伴、同一势力，还是有明确上下级的权力结构。存在明确层级时，可按以下顺序组织：

1. **共同力量先落地**：环境、阵法、队形或共同动作先改变场内状态，让观众知道这群人为何可怕；
2. **个体差异再成立**：通过不同站位、姿态、轮廓、武器、动作或前后景关系辨认关键成员，避免逐个复制同一种特写；
3. **焦点接力有因果**：新人物以进入前景、遮挡解除、动作接点或空间释放接管注意力，旧人物仍留在已建立的位置；
4. **领袖用反差定级**：下属可以高调、快速、占据画面，最高权力者未必更用力；“早已在场、更少动作、更稳构图、更长停留”往往比再次升级特效更有支配感；
5. **关系全景作确认**：最后用可读的高低、远近和中心分布确认领袖、执行者、对象与被控制空间。

若领袖与下属使用同一种降落、抬眼、环绕和慢动作，观众只能看见一组同质化海报，无法读出层级。群像出场只选择一个主要视觉签名；复杂连续运镜按AI能力拆段，并用方向一致的前景遮挡或身体擦镜连接。

## 3. 关键时刻的渲染

### 什么值得完整渲染

关键时刻至少满足一项：

- 人物目标、关系或权力发生明确改变；
- 重要真相首次被确认；
- 人物作出不可逆选择；
- 危险、能力或代价首次真正落地；
- 观众对角色的判断被重新定义；
- 本集主要铺垫得到回收。

音量大、台词狠、角色漂亮或特效多，本身不构成关键时刻。

### 渲染层级

- **主要时刻**：本章最重要的变化，允许完整铺垫、明确落点和余震；
- **次要强调**：帮助主要时刻成立，只选择一种强化手段；
- **普通信息**：以清楚、连续为先，不做仪式化处理。

同一章若所有节点都按主要时刻渲染，就会失去对比。先排序，再分配时长、声音和镜头运动。

### 四阶段结构

1. **铺垫／蓄力**：建立正常状态、危险临界、人物等待或一个未完成动作；
2. **事件落点**：让关键动作、台词、揭示或选择成为唯一主要主体；
3. **短暂停留**：给观众确认“发生了什么”，重要结果不能刚出现就切走；
4. **后果延续**：下一镜必须看见关系、环境、伤势、道具或行动路线已经改变。

四阶段可以压缩在一个长镜头，也可以分布在镜头链中；不要为了形式强行拆成四镜。

### 对比优于堆叠

根据故事只选择一项主强化，再用一项辅助：

- 动静对比：混乱后突然稳定，或平静中突然爆发；
- 声音对比：短暂抽声、单一声音突出、爆点后留下余响；
- 尺度对比：局部与关系全景、人物与环境参照；
- 时间对比：前段快、落点慢，或长时间蓄力后的瞬时动作；
- 构图对比：被遮挡到完整、边缘到中心、受压到占据画面。

不要把急推、慢动作、震屏、停帧、低机位、环绕、粒子和全员反应全部叠在同一时刻。

### 主体保护与余震

- 高光动作开始后，除非观众站位本来就在观察者，不用无关反应打断完整动作。
- 关键台词说完后可在同镜保留表演或结果停留，不必立刻切脸。
- 高光产生的空间、伤势、道具和关系变化必须持续到后续，不能下一镜恢复原状。
- 若删去特效和运镜后事件本身不再重要，说明渲染正在替代故事。

## 4. 强者与反派高光

当人物真正掌控局面时，可使用：

- 低机位或较完整的身体关系；
- 克制的缓慢推进、升降或小幅环绕；
- 让其他人物在前景退让或被迫仰视；
- 更稳定、更有耐心的停留；
- 一个完整动作不被无关反应镜头打断。

“仰拍＋慢速环绕”是可选高光卡，不是所有强者的默认镜头。沉默、静止、平视或背对也可能更强。强者遭突袭、失控或主观崩塌时可以打破稳定。

反派的压迫应来自其能力、选择、后果和对空间的控制，不能只靠低角度和阴影。

## 5. 爆点与转折

爆点前先积累预期，爆点时只强化真正改变故事的瞬间：

- 快切用于并发结果或时间压力；
- 急推用于观众必须立刻读到的认知变化；
- 甩镜用于方向明确的突然事件或遮挡衔接；
- 短暂停顿用于让不可逆结果落地；
- 特写用于证据、动作接点或决定，不是自动拍眼睛。

同一爆点通常选择一种主强化方法。快切、急推、震屏、停帧、失焦和音效抽离不要全部叠加。

## 6. 喜剧

喜剧镜头保护四步：建立正常预期 → 发生偏差 → 留出反应空隙 → 用第三人、道具或后果回收。

- 包袱前不要过早解释；
- 反应镜头只保留最准确的一次；
- 让吐槽者拥有明确空间位置和观察权限；
- 动作喜剧先让观众看清正常动作，再看失误和后果；
- 不用花哨运镜抢走停顿和表演节奏。

## 7. 转场

转场应连接故事关系，而不是作为装饰。可选择：

- 动作匹配：同方向动作在下一场继续；
- 图形匹配：圆形道具、门、月亮、眼睛等形状相接；
- 声音桥：下一场声音提前进入，或上一场声音延续；
- 遮挡衔接：门框、树干、人物、烟雾擦镜；
- 明暗与色调：现实、回忆、梦境或时间变化；
- 因果转场：上一镜决定，下一镜直接展示执行结果。

不要为达到转场比例强行使用无缝转场。场景需要明确断裂时，硬切更准确。

## 8. 系统、卡牌与特殊机制

先说明机制在故事中的功能：提供信息、诱惑、限制、代价、选择或反转。视觉设计必须让观众读懂状态变化：

- 触发前：人物动作或条件；
- 触发时：一个清楚的视觉与声音反馈；
- 触发后：能力、道具或人物状态实际改变；
- 后续镜头：变化持续存在并影响选择。

界面不是自动悬浮UI。若剧本设定为实体卡牌、只有某人可见、传音或空间投影，必须按设定表现。文字需清晰可读，避免乱码和随机符号。

## 9. 大场面与异象

先建立人物与环境参照，再展示规模。镜头顺序可从：正常状态 → 局部异常 → 多点反应 → 空间变化 → 全貌或关键局部 → 人物选择 → 后果。

大全景只有在需要交代规模、方向或结果时使用。奇观必须改变人物处境；不改变故事的云层、粒子、火光和环绕只是装饰。

## 10. 结尾钩子

优先使用：

- 新问题：观众刚得到一个答案，又发现更大的未知；
- 未完成动作：门将开、攻击将至、人物即将看见某物；
- 不可逆决定：人物选择进入、背叛、交出或拒绝；
- 关系变化：握手、分离、站队、拒绝回头；
- 后果显现：伤势、失效、追兵、裂痕、环境异变；
- 情绪余味：故事暂时结束，但一个动作让关系被重新定义。

钩子必须来自当前故事。不要凭空添加怪物眼睛、神秘黑影、电话、爆炸或反派冷笑。

## 11. 使用限制

- 一个场景只选少量与故事直接相关的方法；
- 同一镜头原则上只有一个主要运镜逻辑；
- 导演卡只在用户点名或关键高光确有必要时调用；
- 普通对话、信息交代和日常动作不自动风格化；
- 关键时刻先排序再渲染，重要人物先进入故事再展示气场；
- 故事、人物、连续性与可执行性始终高于镜头标签。
