# Storyboard Director

一套面向商业 AI 短剧、AI 漫剧和 AI 视频制作的电影级分镜 Skill。

它会将完整短剧脚本拆解成可直接用于 AI 视频生成、分镜制作和后期剪辑的正式细分分镜，并重点控制：

- 每集前 3–8 秒的开场吸引力
- 重要角色首次出场、重新登场和身份转变的专门设计
- 原剧情、台词、OS 与 VO 的完整保留
- 景别、角度、构图、运镜和商业短剧节奏
- 人物站位、180°轴线、视线、动作与道具连续性
- 喜剧、反派、爆点、追逐、大场面、系统和卡牌等不同镜头语言
- 单镜头时长与信息承载能力
- AI 视频模型的实际可执行性
- 集尾继续观看的钩子

## 适合什么任务

在以下情况使用：

- 制作短剧分镜
- 拆解镜头
- 设计镜头语言
- 制作 AI 漫剧分镜
- 制作 AI 短剧或视频分镜

仅需修改剧本、评价剧情、写小说、总结剧情或润色台词时，不应使用本 Skill。

## 目录结构

```text
storyboard-director/
├── SKILL.md
├── references/
│   └── director-rules.md
└── agents/
    └── openai.yaml
```

- `SKILL.md`：触发条件、核心工作流、优先级和输出格式。
- `references/director-rules.md`：完整导演规则、特殊段落处理和最终自检。
- `agents/openai.yaml`：Codex 界面中的名称、简介和默认调用提示。

## 安装方法

### 方法一：让 Codex 帮你安装（推荐）

把下面这句话发给 Codex：

```text
请从 https://github.com/katarakinkim-arch/storyboard-director 安装这个 Skill。
```

安装完成后，从下一轮对话开始即可使用。

### 方法二：手动安装

将仓库克隆到个人 Codex Skills 目录：

```bash
git clone https://github.com/katarakinkim-arch/storyboard-director.git ~/.codex/skills/storyboard-director
```

如果该目录中已经存在同名 Skill，请先备份或更换目录名，避免覆盖。

## 怎么调用

### 明确调用

在请求开头写 `$storyboard-director`：

```text
$storyboard-director 请把下面这一集短剧脚本拆成正式分镜。
```

### 自然语言调用

安装后，也可以直接说：

```text
请把这份短剧脚本拆解成适合 AI 视频制作的详细分镜。
```

当请求与分镜制作明确匹配时，Codex 可以根据 Skill 的说明自动判断并调用。若希望确保使用本 Skill，优先采用 `$storyboard-director` 明确调用。

## 建议提供的材料

至少提供完整剧本。条件允许时一并提供：

- 第几集和标题
- 人物参考图与造型设定
- 场景参考图和空间布局
- 道具、卡牌、系统界面参考图
- 世界观、人物关系和特殊能力设定
- 期望的单集时长、画幅和视频模型
- 希望重点加强的角色、情绪、喜剧点或爆点
- 上一集结尾，便于承接开场钩子

资料不足时，Skill 会依据剧本合理完成；缺失信息会实质改变剧情时才应询问。

## 完整调用示例

```text
$storyboard-director

请把下面的第 3 集拆成适合 AI 视频生成的正式分镜。

要求：
1. 单元尽量控制在 30 秒以内。
2. 开场 5 秒必须有吸引力。
3. 强化反派首次正式出场的压迫感。
4. 保留全部台词、OS 和 VO。
5. 人物站位、动作、道具和卡牌状态必须连续。
6. 每个镜头都要写时长、画面、运镜和台词。

人物参考图：已附上
场景参考图：已附上

剧本：
（粘贴完整剧本）
```

## 输出形式

Skill 默认先建立场景站位与轴线，再按自然戏剧阶段划分单元，并逐镜输出：

```text
镜头1：
【时长：0-2秒】
画面：……
运镜：……
台词：……
```

每个单元从 0 秒重新计时，单元内部时间连续。无台词写为 `台词：无`，OS 和 VO 会明确标注。

## 继续更新这套 Skill

实际使用中发现问题时，建议按以下顺序修改：

```text
发现的问题
→ 分析当前规则为什么没有阻止问题
→ 检查是否与旧规则冲突
→ 写成明确、可执行的新规则
→ 使用原出错案例重新测试
```

核心工作流和输出契约放在 `SKILL.md`；详细导演知识放在 `references/director-rules.md`，避免重复和冲突。
