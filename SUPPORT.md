# Support

For usage questions, bug reports, or feature requests, open a GitHub issue:

https://github.com/katarakinkim-arch/storyboard-director/issues

When reporting a problem, include:

- the host product and model used;
- the request that triggered the issue;
- the result you expected;
- the result you received;
- whether reference images or custom constraints were supplied.

Do not include confidential scripts, private credentials, or personal information in public issues.
